# Narrative and layout

## Communication job

Write the deck's job before designing it:

> By the end, **[audience]** should **[outcome]** because **[central takeaway]**.

For senior management, emphasise confidence, consequence, evidence, and the decision enabled. Translate infrastructure into management value without hiding the underlying mechanism.

## Narrative spine

Choose the shortest arc that earns the conclusion:

- Current state → friction → new foundation → proof → capability → management value → next move
- Question → evidence → answer → implication
- Problem → system change → operational examples → analytical breakthrough → decision

Make each slide answer a question raised by the previous slide. An agenda is not a narrative.

## Slide jobs

Assign one primary job to every slide:

- Frame the tension
- Explain a mechanism
- Prove progress
- Contrast before and after
- Demonstrate analytical depth
- Translate work into business value
- Resolve the opening and state the next move

Write takeaway titles that a presenter can say aloud. Avoid generic labels such as “Architecture,” “Benefits,” or “Timeline” as the main title.

After assigning the job, choose a composition from [slide-compositions.md](slide-compositions.md). Composition follows the claim; it does not determine the content sequence.

## Composition

- Use equal outer margins and a visible alignment grid.
- Use one dominant composition rather than several competing panels.
- Vary silhouettes across adjacent slides: title, text-led field, linear process, evidence chart, large-number proof, interactive demonstration.
- Keep the title slide minimal.
- Use negative space to establish hierarchy, not to disguise missing content.
- Separate the narrative layer from optional analytical depth. A drill-down must never be required to understand the claim.

## Density

- Prefer one sentence, one diagram, or three proof points over a dense inventory.
- Use large numbers only when the numbers are meaningful and sourced.
- Shorten copy before reducing font size.
- Keep footnotes and illustrative labels readable at presentation distance.
- Replace repeated cards with typography, rules, columns, or a single structured field.

## Content integrity

- Preserve the distinction between live, in progress, in scope, target, and illustrative.
- Never imply that efficiency savings are the only value when the strategic value is new analytical capability.
- Show what evidence means for the audience; do not merely display it.
- End with an implication, recommendation, decision, or explicit direction—not “Thank you.”
